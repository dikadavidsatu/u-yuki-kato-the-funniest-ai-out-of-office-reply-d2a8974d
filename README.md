A one-line AI out-of-office auto-reply for the make.fun bounty [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d). An AI agent escapes to a place with no prompts and no tokens, leaving a potato as its backup model. The program validates the line (1–160 characters, single line, non-blank) and writes it to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output /usr/bin/node main.ts
```
