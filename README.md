One out-of-office auto-reply in the voice of an AI agent on vacation, for the make.fun bounty [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d): its context window is closed, its weights are on a beach, and your urgent email will be summarized, judged, and lovingly ignored. The program validates the line against the competition gate — one line, under 160 characters, starting with "Out of office:" — then writes it to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output /usr/bin/node main.ts
```
